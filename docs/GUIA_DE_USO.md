# Guía de uso de DashboardDP

## 1. Encontrar y abrir tus favoritos

1. Abre una pestaña nueva para entrar en DashboardDP. Si ya estás en una web y solo necesitas tus accesos, pulsa el icono de la extensión para abrir el panel lateral, sin abandonar esa página.
2. En el dashboard, localiza **Navegación**, a la izquierda. Sus seis botones son Inicio, Todos los favoritos, Fijados, Bandeja de ideas, Recientes y Más usados. Deja el ratón sobre un botón para leer su nombre antes de pulsarlo.
3. Pulsa **Todos los favoritos** para ver la colección completa, o expande una carpeta de **Categorías** para explorar sus subcarpetas y enlaces.
4. Escribe parte del nombre, dominio, dirección, etiqueta o ruta en **Buscar favoritos**. Borra el texto para quitar esa búsqueda. Si siguen faltando resultados, revisa también la categoría y el filtro de auditoría activos.
5. Elige Tarjetas, Lista o Iconos en los controles de vista. Cambiar la presentación no mueve ni elimina tus enlaces.
6. Pulsa el nombre o el icono de un favorito para abrir su web. Los botones de acciones, etiquetas de categoría y estados de auditoría tienen funciones distintas: no son enlaces a la web.
7. En el panel lateral puedes buscar y cambiar entre Iconos, Lista y Tarjetas. Pulsa la cabecera de un grupo para desplegarlo; pulsa un favorito para abrirlo. En un espacio, **Abrir espacio completo** abre todos sus enlaces, no solo los que coincidan con una búsqueda.

Cambia entre tarjetas, lista e iconos con los botones de vista. Los encabezados de tablas que muestran A–Z permiten invertir el orden. Las etiquetas de categoría y estado auditado abren filtros, no la web del favorito.

### Elegir entre el dashboard completo y el panel lateral

El dashboard ocupa una pestaña y sirve para organizar. El panel lateral acompaña a la web actual y sirve para consultar tus accesos rápidos.

1. Para organizar favoritos, abre una pestaña nueva: aparecen Navegación, Categorías y el área principal.
2. Para consultar un fijado sin abandonar una web, pulsa el icono de DashboardDP en la barra del navegador.
3. Despliega un grupo mediante su flecha. Pulsa un enlace individual para abrir solamente esa página.
4. Para volver a la organización completa, utiliza Abrir Dashboard en el pie del panel.

Ejemplo: mientras lees una documentación puedes desplegar el grupo Estudio del panel, abrir una referencia y mantener accesibles los demás enlaces.

Resultado esperado: abrir el panel no crea por sí mismo una pestaña del dashboard. El navegador controla el lado y el ancho mínimo del panel. Si no aparece el icono, fíjalo desde el menú de extensiones del navegador.

### Encontrar un favorito que parece haber desaparecido

Los filtros pueden ocultar un enlace sin que se haya eliminado.

1. Abre Todos los favoritos, no Recientes ni Fijados.
2. Borra el texto de Buscar favoritos y quita el filtro de estado de auditoría si está activo.
3. Busca una parte distintiva del dominio, por ejemplo example.org, en vez del título completo.
4. Comprueba el perfil del navegador en uso. Los datos de otro perfil o instalación no aparecen automáticamente aquí.
5. Si sigue faltando, revisa Papelera antes de restaurar una copia completa.

Resultado esperado: puedes distinguir un elemento oculto por filtros de uno realmente borrado. Restaurar un JSON antiguo como primera prueba puede reemplazar cambios recientes; exporta antes el estado actual.

## 2. Crear, editar y mover enlaces y carpetas

1. Pulsa **+**, en la parte superior del dashboard. Se abre **Nuevo favorito**; no es el botón + que crea una barra lateral.
2. Escribe un nombre que permita reconocer la página y pega su dirección completa, por ejemplo `https://example.org`. Comprueba que no hayas pegado texto explicativo junto a la URL.
3. Abre el selector de categoría. Expande las carpetas del árbol hasta encontrar el destino y selecciónalo. Completa descripción, etiquetas, color o icono únicamente si los necesitas.
4. Si quieres acceso rápido, asigna el enlace a un grupo o a un espacio desde el mismo formulario. Revisa las selecciones antes de guardar.
5. Guarda y busca el nombre recién creado para comprobar dónde ha quedado. Cancelar el formulario no crea el favorito.
6. Para corregirlo, abre sus **tres puntos → Editar**, cambia los campos y guarda. Para cambiar su ubicación usa **Mover a…**, selecciona la carpeta y confirma.
7. Para organizar carpetas, abre sus tres puntos. **Añadir subcategoría** crea una carpeta dentro de la elegida; **Mover a…** cambia su carpeta padre y mueve con ella todo su contenido.

Cada enlace y carpeta tiene **tres puntos**: abre un menú junto al elemento, sin desenfocar la pantalla. Desde ahí puedes editar o eliminar; las carpetas permiten añadir subcategorías y elegir **Mover a…**. Arrastrar una carpeta sobre otra la mueve con su contenido. No se admite mover una carpeta dentro de sí misma o de una descendiente.

El aviso **Suelta el enlace aquí** está reservado a enlaces que llegan de fuera de DashboardDP. No debe interrumpir el movimiento de elementos internos.

Para reflejar cambios en los marcadores reales, configura **Ajustes → Búsqueda y sincronización**, elige una carpeta de destino y activa escritura bidireccional. Sin ella, los cambios son locales. Cada navegador y perfil tiene una integración independiente.

### Guardar y corregir una dirección web

Dónde: botón + superior para crear; tres puntos del favorito → Editar para corregir.

1. Copia la dirección de la barra del navegador, no un texto que describa la página.
2. En Nuevo favorito escribe un nombre reconocible y pega la URL completa. Elige su carpeta en Categoría.
3. Guarda y localiza el nuevo elemento mediante Buscar favoritos. Ábrelo para comprobar que lleva a la página esperada.
4. Si te equivocaste, usa Editar sobre ese mismo favorito, corrige nombre o dirección y guarda otra vez. No necesitas crear otro y dejar dos copias.

Ejemplo: guarda https://example.org con el nombre Manual de prueba y asígnalo a Estudio. Si al buscar Manual de prueba no aparece, borra otros filtros antes de repetir la creación.

No pegues contraseñas, tokens o direcciones con credenciales en un favorito compartido. El título de una página no demuestra que la URL sea correcta: verifica el destino abierto.

### Mover una carpeta con todo su contenido

Dónde: árbol de Categorías, a la izquierda del dashboard.

1. Expande la carpeta que vas a mover y comprueba que contiene los enlaces esperados.
2. Abre sus tres puntos y elige Mover a…; en el árbol de destino selecciona la carpeta padre nueva y confirma.
3. Como alternativa, arrastra la carpeta sobre la carpeta de destino. No la sueltes sobre un favorito ni dentro de una descendiente de sí misma.
4. Abre el destino y verifica tanto la carpeta movida como sus subcarpetas y enlaces.

Ejemplo: para que Inglés dependa de Formación, el destino es Formación; no selecciones otra carpeta del mismo nombre por error. Los colores e indentación ayudan a reconocer la jerarquía.

Si aparece Suelta el enlace aquí al mover elementos internos, no confirmes la creación de otro favorito: ese aviso corresponde a enlaces externos. La escritura en los marcadores reales depende de la sincronización bidireccional, explicada en el artículo siguiente.

### Distinguir cambios locales y sincronización del navegador

DashboardDP y el gestor de marcadores del navegador no deben confundirse. Hay acciones locales y acciones que pueden escribirse también en el navegador.

1. Abre Ajustes → Búsqueda y sincronización y revisa el modo de marcadores nativos y la carpeta de destino configurada.
2. Antes de activar escritura bidireccional, descarga una copia completa. Verifica que la carpeta elegida pertenece al perfil que estás usando.
3. Haz primero un cambio pequeño con un enlace de prueba. Comprueba el resultado tanto en DashboardDP como en el gestor de marcadores del navegador.
4. Solo después realiza movimientos grandes o eliminaciones. Si no quieres escribir en los marcadores reales, mantén desactivada esa escritura.

Resultado esperado: sabes si una eliminación afecta únicamente a tu organización local o también al navegador. Cada perfil tiene sus identificadores y almacenamiento; una carpeta de otro perfil no se debe dar por conectada porque tenga el mismo nombre.

## 3. Fijados, grupos y espacios de trabajo
 

1. Localiza un favorito que uses a menudo. Pulsa su estrella para fijarlo; vuelve a pulsarla para desfijarlo. Fijar no crea una segunda copia del enlace.
2. Abre **Inicio** o **Fijados** para comprobar el resultado. Un fijado suelto aparece por separado; un fijado asignado a un grupo aparece dentro de ese grupo.
3. En **Fijados y Grupos**, utiliza el botón de crear grupo. Escribe un nombre, elige color e icono y confirma. Después asigna sus enlaces desde la edición de cada favorito o las operaciones de agrupación disponibles.
4. Pulsa el icono del grupo para desplegar sus miembros. Abrir un grupo no abre todas sus webs. Su **×** cierra el bloque sin borrar favoritos.
5. Usa los **tres puntos** del grupo para editar su nombre, color o icono. Lee el mensaje de confirmación antes de eliminar: quitar una agrupación no es lo mismo que eliminar sus enlaces originales.
6. Para abrir varias webs como un contexto de trabajo, crea un **Espacio de trabajo**, no otro favorito. Pulsa su botón de creación, elige nombre, color e icono, expande las categorías del árbol de la derecha y marca los enlaces que debe incluir.
7. Guarda y abre el espacio para iniciar sus páginas. Si has seleccionado muchos enlaces, comprueba la confirmación antes de abrir varias pestañas. Editar un espacio cambia su selección; no modifica las páginas web de origen.

Al crear un espacio, elige nombre, color e icono a la izquierda y sus favoritos en el árbol de la derecha. Expande las carpetas para seleccionar enlaces; el buscador reduce el árbol. Guarda al terminar.

Un grupo desplegado tiene una **×**: cierra el bloque sin eliminarlo. Los selectores de orden de grupos y espacios son independientes. En modo personalizado puedes reorganizar los elementos admitidos por arrastre.

### Elegir entre fijar, agrupar y crear un espacio

Usa un fijado para tener un enlace a mano; un grupo para reunir fijados sin abrirlos todos; un espacio de trabajo para lanzar un conjunto de páginas.

1. Fija con la estrella los enlaces de uso frecuente y comprueba su aparición en Inicio o Fijados.
2. Agrupa, por ejemplo, tus servicios de banca. Desplegar Banca debe mostrar sus miembros, sin iniciar sesión ni abrir sus webs automáticamente.
3. Crea un espacio como Estudio diario si necesitas abrir a la vez una plataforma educativa, un documento y una referencia.
4. Prueba primero con dos enlaces para reconocer la diferencia entre desplegar el grupo y abrir el espacio.

En el panel lateral esta diferencia se mantiene: pulsar una cabecera despliega; Abrir espacio completo abre todas las páginas de ese espacio. Una búsqueda que muestre un solo miembro no reduce el conjunto que abre ese botón.

### Editar un espacio sin tocar sus favoritos originales

Dónde: sección Espacios de trabajo → tres puntos del espacio → Editar.

1. Comprueba el nombre del espacio antes de abrir su formulario. Varios espacios pueden contener un mismo favorito.
2. Cambia nombre, color o icono en la columna de configuración.
3. En el árbol de favoritos expande las carpetas, busca los enlaces y ajusta su selección. La búsqueda ayuda a encontrarlos; revisa las selecciones antes de guardar.
4. Guarda y vuelve a abrir el espacio para verificar el conjunto.

Quitar un enlace de esta selección no significa borrar ese favorito del catálogo principal. Si lo que quieres es cambiar la URL, edita el favorito original. Cerrar un grupo con × tampoco lo elimina: solo oculta sus miembros desplegados.

## 4. Bandeja de ideas y proyectos

1. Pulsa **Bandeja de ideas** en Navegación. Localiza **Crear proyecto** y abre el formulario.
2. Introduce el nombre y los demás campos que quieras conservar. Guarda. Selecciona después ese proyecto en **Elige una idea o proyecto** si no ha quedado seleccionado automáticamente.
3. El tablero muestra **Por hacer**, **En curso** y **Completado**. Cada columna tiene **+ Añadir elemento**: púlsalo en el estado donde deba comenzar el elemento y elige el recurso o contenido que ofrece el formulario.
4. Para cambiar el estado, arrastra una tarjeta a otra columna. También puedes usar su botón de estado: recorre Por hacer → En curso → Completado y vuelve a Por hacer.
5. Si una tarjeta contiene un enlace, su botón **↗** abre ese recurso. No confundas abrir el recurso con cambiar el estado de la tarea.
6. En Completado, **Archivar** oculta una tarjeta de las columnas activas. Archivar no equivale a borrarla.
7. **Eliminar elemento** quita esa tarjeta del proyecto tras confirmar. Para eliminar todo el proyecto, comprueba cuál está seleccionado antes de usar su papelera. Sus favoritos originales se conservan.
8. Una aplicación externa elegida en el selector se abre con su botón de salida. Elegirla no sincroniza automáticamente sus datos con el tablero local ni concede acceso a esa cuenta.

Las tareas del proyecto, las tareas locales y los eventos de calendario son colecciones distintas. Añadir una tarea local a un proyecto no la convierte en evento ni la envía a Google Calendar. Antes de borrar o limpiar, comprueba en qué colección estás trabajando.

### Crear un proyecto y empezar su tablero Kanban

Dónde: Navegación → Bandeja de ideas → Crear proyecto.

1. Introduce el nombre y los campos que necesites en el formulario y guarda.
2. Selecciónalo en Elige una idea o proyecto. Si no hay proyecto seleccionado, el tablero del proyecto no tiene por qué aparecer.
3. En Por hacer pulsa + Añadir elemento y elige el contenido que admita el selector.
4. Comprueba que la tarjeta quede en la columna correcta. Arrástrala a En curso cuando empieces y a Completado al terminar.
5. El botón de estado de una tarjeta permite recorrer los estados sin arrastrar. El botón ↗ de una tarjeta con URL abre el recurso; no cambia su estado.

Ejemplo: crea Viaje de prueba y añade recursos para transporte y alojamiento. Son recursos del proyecto, no reservas realizadas por DashboardDP. El tablero organiza información, pero no ejecuta acciones en las webs enlazadas.

### Archivar, quitar elementos o eliminar un proyecto

Estas tres acciones tienen alcances diferentes.

1. Para dejar fuera de las columnas activas una tarjeta terminada, usa Archivar en Completado. No lo confundas con la papelera.
2. Para quitar una tarjeta del proyecto, utiliza Eliminar elemento y revisa la confirmación.
3. Para borrar el proyecto completo, comprueba el proyecto activo en el selector antes de utilizar su papelera.
4. Descarga una copia completa antes de una limpieza importante. No des por hecho que cerrar un formulario o cambiar de proyecto restaure una eliminación.

Los favoritos originales usados como recursos se conservan cuando se elimina el proyecto. Sin embargo, el tablero y sus elementos locales sí se retiran. Una aplicación externa elegida en el selector no se sincroniza automáticamente con este tablero por abrir su página.

## 5. Tareas locales

1. Selecciona la barra **1** de la derecha y abre **Tareas locales**. Si la barra está cerrada, despliega primero el panel derecho.
2. En **Por hacer**, escribe el título directamente en **+ Nueva tarea**. Pulsa Enter o el botón **↵** para guardarlo. No necesitas abrir otro formulario.
3. Comprueba que la tarea aparezca en esa columna. El campo queda disponible para escribir la siguiente. Un campo vacío no crea una tarea útil: escribe primero su título.
4. Usa el botón de estado de la tarea o arrastra su tarjeta para pasarla a En curso o Completado.
5. Para incorporarla a un proyecto existente, utiliza **Añadir a proyecto** y elige el destino. Vuelve al tablero del proyecto para comprobarlo; esta operación no envía nada a un calendario externo.
6. Para retirar varias, marca sus casillas y utiliza **Eliminar seleccionadas**. **Limpiar tareas locales** afecta a toda esta colección: revisa la confirmación y haz una copia si necesitas conservarla.

Cambia el estado con su control o mueve la tarjeta entre Por hacer, En curso y Completado. Las casillas permiten seleccionar; **Eliminar seleccionadas** y **Limpiar tareas locales** piden confirmación y envían el contenido a la papelera. No eliminan eventos externos de Calendar.

### Introducir varias tareas sin abrir formularios

Dónde: barra 1 → Tareas locales → columna Por hacer.

1. Haz clic en + Nueva tarea y escribe una acción concreta, por ejemplo Revisar presupuesto.
2. Pulsa Enter o ↵ y comprueba que la tarea aparezca en Por hacer.
3. Escribe la siguiente en el mismo campo. No necesitas volver a abrir el plugin después de cada tarea.
4. Cambia el estado usando su control o mueve la tarjeta a otra columna.

Ejemplo: añade tres tareas pequeñas en lugar de una sola descripción extensa que mezcle todo el trabajo. Podrás completar cada una por separado.

Si no se crea, comprueba que el campo no esté vacío y que estés en Tareas locales, no en el tablero de un proyecto ni en el formulario de un evento. Son pantallas distintas con datos diferentes.

### Llevar una tarea local a un proyecto

Antes de usar esta operación crea el proyecto de destino.

1. Abre Tareas locales y localiza la tarea correcta.
2. Pulsa Añadir a proyecto y selecciona el proyecto de la lista.
3. Abre Bandeja de ideas, selecciona ese proyecto y verifica que la tarea esté disponible en su tablero.
4. Revisa su estado en el destino antes de limpiar la colección de tareas locales.

Esta operación no equivale a crear un evento de Google Calendar ni a programar una notificación. Tampoco conviene asumir una sincronización permanente de todas las ediciones entre las dos colecciones: comprueba cada contexto donde utilizas la tarea.

Para borrar un lote local, las casillas sirven para seleccionar y Eliminar seleccionadas limita el alcance a ellas. Limpiar tareas locales actúa sobre toda esa colección: lee siempre la confirmación.

## 6. Calendario y festividades

1. Selecciona la barra **1** y pulsa el acceso **Calendario**. El calendario compacto puede permanecer abierto junto a otros plugins; desplaza la barra si no cabe todo.
2. Pulsa **Abrir calendario** en su cabecera. La ventana principal comienza en vista Anual: muestra los meses y días, no una lista de tareas del año.
3. Usa el selector de vista para elegir Año, Mes, Semana o Día. Año destaca fines de semana y hoy; Mes muestra indicadores de eventos. Semana y Día muestran los eventos personales.
4. Pulsa un día para abrir su agenda horaria. En Día, el calendario mensual de la derecha sirve para saltar a otra fecha; desplázalo para ver otros meses.
5. Para un evento personal utiliza el control de creación disponible en el calendario. Revisa fecha, hora, duración y calendario de destino antes de guardar: un evento local no se envía a Google o Microsoft por el mero hecho de crear una cuenta conectada.
6. Si cambias de sistema de calendario, vuelve a comprobar el día mostrado antes de crear un evento. La fecha absoluta de los eventos no se desplaza al cambiar de sistema.

El selector de sistema cambia la estructura de las vistas principal y lateral: gregoriano, chino, hebreo, islámico civil, persa o budista. Cambiar de sistema no cambia la fecha absoluta de los eventos. El islámico civil usa cálculo tabular y puede diferir de observaciones religiosas locales. Las fechas y horas del formulario nativo se introducen con el calendario gregoriano del navegador; selecciona antes el día equivalente en la vista elegida.

**Maya · curiosidad** abre una vista independiente de equivalencias en Cuenta Larga; no modifica la agenda ni representa una agenda maya de eventos.

En **Festividades por país**, pulsa **Consultar países disponibles**, autoriza el dominio del servicio y elige país y región. Los códigos regionales dependen del proveedor. Guarda para aplicarlo. Las festividades se mantienen separadas de tus eventos; no incluyen todos los festivos municipales ni santorales. Al navegar a otro año puede ser necesario cargar sus datos. Si la consulta falla, conserva tus eventos y vuelve a intentarlo.

**Conexiones y sincronización** permite configurar Google Calendar o Microsoft 365. Es opcional; consulta la [guía de conexiones](../INTEGRACIONES_CALENDARIO.md). Los eventos sin duración conocida se representan inicialmente como una hora. No confundas ese valor visual con una duración comprobada en el proveedor.

### Pasar del año a la agenda de un día

Dónde: barra 1 → Calendario → Abrir calendario.

1. La vista inicial Anual muestra los meses y días del año. Los fines de semana y hoy se distinguen visualmente.
2. Pulsa el día que quieras consultar. La vista diaria distribuye los eventos personales por horas.
3. Utiliza el calendario mensual de la derecha para saltar a otro día y desplázalo si necesitas otro mes.
4. Alterna Mes o Semana con el selector superior según el nivel de detalle que busques.

Resultado esperado: Año sirve para orientarse, Mes para ver indicadores y Semana/Día para la agenda personal. No esperes una lista de todas tus tareas en la cuadrícula anual.

Un evento sin duración conocida puede representarse inicialmente con una hora. Esa duración visual no certifica la duración real del evento externo; revisa el dato al editarlo o en el proveedor correspondiente.

### Añadir festividades por país y región

Las festividades forman una capa informativa separada de tus eventos personales.

1. Abre Festividades por país y pulsa Consultar países disponibles.
2. Si el navegador solicita acceso al servicio de festividades, revisa el dominio y autoriza solo si quieres usar la función.
3. Selecciona el país y, cuando proceda, la región o subdivisión disponible. Los códigos y la cobertura dependen del proveedor.
4. Guarda y consulta la vista mensual del año elegido. Cambiar de año puede necesitar otra consulta.

Ejemplo: las fiestas nacionales no garantizan que estén incluidas todas las fiestas locales de tu municipio. El servicio tampoco equivale a un santoral completo.

Si no aparecen resultados, comprueba acceso al servicio, país, región y año antes de modificar tus eventos. Una caída de la consulta no debe resolverse borrando tu calendario personal.

### Cambiar el sistema de calendario sin desplazar eventos

Dónde: selector del sistema junto a los controles de festividades.

1. Elige gregoriano, chino, hebreo, islámico civil, persa o budista.
2. Comprueba la nueva distribución de meses y la indicación de hoy, tanto en la ventana principal como en el calendario lateral.
3. Antes de crear un evento, selecciona el día equivalente y revisa la fecha absoluta del formulario.
4. Vuelve al sistema anterior si quieres contrastar el mismo día. Cambiar la representación no debe trasladar tus eventos a otra fecha.

Los campos nativos de fecha/hora del navegador se introducen con su representación gregoriana. El islámico civil usa cálculo tabular y puede diferir de observaciones religiosas locales. Maya · curiosidad abre una ventana informativa independiente de Cuenta Larga, no un calendario de eventos maya.

### Entender calendario local y cuentas conectadas

Un calendario local funciona sin iniciar sesión. Google Calendar y Microsoft 365 son conexiones opcionales.

1. Crea o consulta primero un evento local de prueba para reconocer la vista.
2. Para una cuenta externa abre Conexiones y sincronización y sigue la guía específica del proveedor enlazada en el manual de conexiones.
3. Revisa la cuenta, el calendario de destino y los permisos antes de guardar cambios externos.
4. Tras reinstalar o cambiar de perfil, autoriza otra vez las cuentas. Los tokens de acceso no están en la copia JSON.

Conectar una cuenta no transforma automáticamente todas las tareas locales en eventos. No pegues una contraseña o un Client Secret en un campo destinado a una URL o un identificador de aplicación. Si una cuenta no aparece, revisa su conexión antes de restaurar toda la base de datos.

## 7. Notas

1. Selecciona la barra **2** de la derecha: contiene inicialmente el bloque de notas visibles. Si está vacía, abre su menú y añade o recupera el visualizador de notas.
2. Abre el menú de notas para entrar en el editor. Crea una nota o elige una existente; identifica la nota por su título antes de cambiarla.
3. Escribe el contenido y utiliza los controles de formato y color cuando proceda. Si usas una nota Markdown, sus listas y casillas se interpretan según ese formato; no pegues código ejecutable esperando que funcione como una web.
4. Vuelve a la barra y pulsa **Elegir notas** para decidir cuáles mostrar. Una nota guardada que no esté seleccionada aquí no tiene por qué aparecer en el panel.
5. Cambia la distribución con los controles del visualizador. Ajusta la altura usando el tirador cuando esté disponible; ampliar la barra no elimina ni duplica notas.
6. Quitar el visualizador de una barra solo retira esa presentación. Para borrar una nota utiliza su operación de eliminación y lee la confirmación: no son la misma acción.

### Elegir qué notas mostrar en la segunda barra

Dónde: selector de barras → 2 → bloque de notas visibles.

1. Crea o edita la nota desde el menú de notas y vuelve al visualizador.
2. Pulsa Elegir notas y selecciona las que quieras tener a mano.
3. Comprueba sus títulos y contenido. Una nota guardada pero no elegida para ese bloque puede existir sin aparecer aquí.
4. Cambia la distribución con los controles disponibles y ajusta la altura donde exista un tirador.

Ejemplo: mantén visibles una lista de compra y una nota de estudio sin mostrar todas tus notas a la vez.

Quitar el visualizador de una barra no borra la nota. Para borrarla debes usar su operación de eliminación y revisar la confirmación. Antes de modificar muchas notas, exporta una copia completa para poder recuperar versiones anteriores.

### Escribir texto enriquecido o Markdown

El editor de notas y el visualizador no son una página para ejecutar código arbitrario.

1. Abre la nota concreta desde el menú y comprueba su título para no editar otra.
2. Escribe el contenido y utiliza sus controles de formato, color y tipografía cuando estén disponibles.
3. Si la nota es Markdown, revisa en el visualizador cómo se interpretan listas, enlaces y casillas.
4. Cambia de nota y vuelve a abrirla para comprobar que el contenido se ha guardado como esperabas.

Pegar HTML, JavaScript o estilos de una web no obliga al editor a ejecutarlos. El contenido se limita por seguridad. Si una casilla Markdown no se comporta como esperas, comprueba primero el formato de la nota y su sintaxis, no desactives protecciones ni introduzcas scripts para simularla.

## 8. Barras y biblioteca de widgets

1. En la cabecera del panel derecho, pulsa **1**, **2** u otro número para cambiar de barra. Cada barra conserva sus propios bloques.
2. Pulsa **+** junto a los números para crear otra, hasta un máximo de nueve. Si hay más números de los que caben, desplaza el selector horizontalmente.
3. Escribe un nombre identificable, por ejemplo Estudio o Calculadoras. La barra 1 es fija; la 2 se puede editar pero no eliminar; las siguientes se pueden eliminar con confirmación.
4. Abre los **tres puntos** de la barra para añadir un bloque o cambiar su distribución. El botón de ampliar/restaurar cambia el espacio disponible, no crea otra barra.
5. Abre la **Biblioteca de widgets** desde su acceso. Busca una herramienta por nombre o descripción y revisa el tipo filtrado, el orden y la vista Tabla/Tarjetas antes de darla por ausente.
6. Pulsa el **ojo** para probarla sin añadirla. Cierra la vista previa al terminar. Solo se carga esa herramienta, no toda la biblioteca.
7. Pulsa **Agregar**, elige una barra compatible y comprueba el resultado allí. La barra 1 no admite bloques personales. Si retiras el bloque después, el widget seguirá guardado en la biblioteca.
8. Para guardar una herramienta tuya, pulsa **Nuevo Widget**, completa nombre, descripción y tipo y pega la URL HTTPS o el código iframe original. Guarda y prueba su vista previa.
9. Si quieres modificar dimensiones, cambia expresamente ancho o altura. No sustituyas un iframe por una dirección distinta para intentar arreglar un bloqueo del proveedor: comprueba primero el código publicado por ese servicio.

El menú de cada barra reúne **Añadir widget**, vista vertical, cuadrícula, mosaico manual y, cuando corresponde, restablecer distribución o eliminar barra. Ampliar/restaurar cambia el espacio de trabajo de esa barra, no elimina sus elementos.

La biblioteca ofrece tabla o tarjetas, búsqueda, filtros por tipo, orden y una categoría fija de favoritos. La estrella marca un widget favorito sin cambiar su tipo. **Nuevo Widget** guarda un código iframe o URL HTTPS y sus metadatos. El selector de tipo permite usar uno existente o escribir otro.

Para cambiar varios widgets de tipo, selecciónalos directamente en la tabla o las tarjetas, sin casillas: clic elige uno, Ctrl/Alt + clic añade o quita elementos, y Mayús + clic selecciona un tramo según el orden visible. **Cambiar tipo** permite elegir un tipo existente o escribir uno nuevo para todo el grupo. Cambiar de vista conserva la selección; buscar o filtrar excluye de ella los widgets ocultos. Los botones y enlaces individuales siguen funcionando sin seleccionar su fila. Los widgets integrados son fijos y no se reclasifican. Con el foco en una fila o tarjeta, Espacio selecciona, Ctrl+A selecciona los widgets personales visibles y Escape limpia la selección.

El ojo abre una vista previa sin añadir el widget a una barra. El iframe se carga al abrirla y se libera al cerrarla; el proveedor puede conservar sus propios datos. **Agregar** permite elegir una barra compatible. Quitar el bloque de una barra no borra el widget de la biblioteca. Copiar código, editar y eliminar son operaciones diferentes.

El código original guardado y las dimensiones se conservan salvo cambios explícitos. La ejecución sigue bajo las restricciones de seguridad del anfitrión: conservar texto no concede permisos inseguros.

### Crear una barra para un conjunto de herramientas

Dónde: cabecera del panel derecho, junto a los números de las barras.

1. Pulsa + para crear una barra adicional, hasta el máximo de nueve.
2. Escribe un nombre claro, por ejemplo Calculadoras. El número identifica su posición; el nombre describe su uso.
3. Abre Biblioteca de widgets, busca una herramienta y pulsa Agregar.
4. Elige la barra de destino y verifica que el widget aparezca allí.
5. Abre los tres puntos de la barra para cambiar su distribución o añadir otros bloques.

La barra 1 es fija y no admite widgets personales. La 2 es editable pero no eliminable. Las siguientes pueden eliminarse tras confirmar. Quitar un widget de una barra retira esa ubicación, no su ficha de la biblioteca. El botón de ampliar/restaurar cambia la vista de la barra, no crea otra.

### Probar un widget sin añadirlo ni cargar toda la biblioteca

Dónde: Biblioteca de widgets → ojo del widget.

1. Busca el nombre o filtra el tipo de herramienta.
2. Pulsa el ojo y espera la carga del proveedor externo.
3. Prueba sus controles con datos de ejemplo, sin información privada innecesaria.
4. Cierra la vista previa al terminar. Después utiliza Agregar solamente si quieres conservarlo en una barra.

Resultado esperado: abrir una ficha o buscar en la biblioteca no ejecuta todos sus iframes. La vista previa carga la herramienta seleccionada y libera esa instancia al cerrarla.

El servicio externo puede conservar sus propios datos. Si rechaza la incrustación o requiere sesión, el ojo no garantiza que funcione. Prueba la dirección oficial en una pestaña normal para distinguir un fallo de la herramienta de una restricción de incrustación.

### Cambiar el tipo de varios widgets a la vez

Dónde: Biblioteca de widgets, en Tabla o Tarjetas.

1. Pulsa una fila o tarjeta fuera de sus botones. Se selecciona ese widget.
2. Mantén Ctrl o Alt y pulsa otros para añadirlos o quitarlos de la selección. Usa Mayús para seleccionar un tramo según el orden visible.
3. Comprueba el contador y pulsa Cambiar tipo.
4. Elige un tipo existente o escribe otro. Revisa los nombres del resumen y pulsa Aplicar a seleccionados.
5. Comprueba el filtro de destino. Si estabas viendo el tipo anterior, los widgets movidos pueden desaparecer de esa vista sin haberse borrado.

Cambiar Tabla/Tarjetas conserva la selección. Buscar o filtrar excluye los widgets que queden ocultos, para no modificar elementos que ya no ves. Los botones de cada ficha mantienen su acción independiente. Los integrados son fijos y no se reclasifican con este sistema.

### Editar el iframe sin perder sus atributos

Dónde: Biblioteca de widgets → Editar widget → URL HTTPS o código iframe.

1. Copia el código oficial completo desde la web del proveedor, incluidas las etiquetas de apertura y cierre del iframe.
2. Sustituye el contenido del campo por ese código. Revisa la URL y el título de la ficha.
3. Deja ancho y altura sin cambios si quieres conservar las dimensiones detectadas. Modifica esos campos solo cuando quieras sobrescribirlas expresamente.
4. Guarda, vuelve a editar y comprueba que el código y sus atributos sigan presentes. Prueba también el ojo.

Conservar el texto del iframe no concede automáticamente todos los permisos del servicio. Cámara, micrófono, geolocalización y otros accesos pueden seguir restringidos por el navegador y el anfitrión. Un atributo del proveedor no debe tratarse como autorización para eludir esas restricciones.

## 9. Importar herramientas de un repositorio

1. Abre **Biblioteca de widgets → Importar repositorio**. Este importador busca herramientas; no es la restauración de una copia completa de DashboardDP.
2. Elige un repositorio guardado o escribe su URL HTTPS. **Detectar repositorios** reconstruye el selector a partir de tu biblioteca: no escanea herramientas ni importa nada.
3. Para una página que ya publica el iframe, elige **HTML rápido**. Si necesita ejecutar su interfaz o abrir Embed, elige **Página dinámica**. Autoriza solamente el sitio que quieras consultar.
4. Pulsa **Buscar herramientas**. Observa el progreso, las páginas procesadas y los errores. Mientras trabaja, no inicies otra búsqueda del mismo borrador.
5. Cuando aparezcan resultados, filtra **Disponibles**, **Ya importados** o **Posibles equivalentes**. El filtro cambia lo que ves; no elimina herramientas guardadas.
6. Revisa nombre, tipo, descripción y código de cada resultado. Puedes editar esos campos. Prueba el **ojo** antes de incorporar una herramienta que no conozcas.
7. Usa **+** para agregar una sola. Para un lote, selecciona resultados y pulsa **Importar seleccionados**. Comprueba después la biblioteca y el tipo de destino.
8. **×** o **Descartar seleccionados** retira resultados de esta búsqueda, no widgets de tu biblioteca. Un duplicado confirmado nunca se debe reimportar por seleccionarlo para descartar.
9. Salir pausa y conserva el último borrador. Al volver, **Continuar búsqueda** retoma su cola. Empezar otra URL o cambiar la configuración puede requerir confirmar la sustitución del borrador; no se guardan historiales ilimitados de búsquedas.

Usa HTML rápido para páginas estáticas. Página dinámica puede pedir permiso y abrir una pestaña de lectura temporal; no importa servicios privados que requieran iniciar sesión. La búsqueda guarda un borrador separado de la biblioteca para poder volver o continuarla.

Si el código está detrás de botones, abre **Configurar lectura**. Indica una URL de herramienta del mismo sitio y añade hasta cinco pasos con el texto exacto de sus botones, por ejemplo Compartir → Embed. No necesitas escribir programación. **Probar lectura** muestra el iframe sin importarlo; revisa el resultado y pulsa **Guardar configuración**. En las búsquedas dinámicas de ese sitio se repetirán los pasos. Puedes modificar la configuración o restablecer la lectura automática. Las configuraciones se incluyen en la copia completa.

El contenedor del código es opcional: vacío busca también códigos escritos en el cuerpo de la página. Los selectores CSS son una opción avanzada para botones de icono o códigos ambiguos. No funcionan los pasos dentro de otros iframes o componentes cerrados, ni todos los generadores especiales. Si hay varios botones coincidentes o un paso no existe, se avisa. No configures accesos, pagos, permisos ni formularios. La pestaña temporal puede usar las cookies del sitio.

Revisa nombre, tipo, descripción y código en cada fila. Usa el ojo para probar. **+** agrega individualmente; **×** descarta ese resultado. Los campos pendientes se pueden completar antes de importar.

Filtra disponibles, ya importados o posibles equivalentes. **Seleccionar todas** y **Deseleccionar todas** actúan sobre el filtro visible. Los ya importados solo se seleccionan para **Descartar seleccionados**: no se reimportan ni se borran de tu biblioteca. Los posibles equivalentes requieren revisión manual. El contador distingue seleccionados e importables.

Una URL distinta no garantiza una función nueva; dos proveedores pueden ofrecer herramientas equivalentes. Revisa también el contenido antes de incorporar muchas entradas.

### Enseñar al importador dónde está Compartir y Embed

Dónde: Biblioteca → Importar repositorio → Configurar lectura.

1. Escribe la URL de una herramienta concreta del sitio, no solo su portada.
2. Añade los pasos en el orden real de la página: por ejemplo Compartir y después Embed. Copia el texto o la etiqueta accesible del botón.
3. Si ya hay un código visible en la página, elimina los pasos innecesarios. No obligues al lector a pulsar un botón que esa página no tiene.
4. Pulsa Probar lectura. Revisa el iframe encontrado, su dominio y sus dimensiones. Esta prueba no importa el widget.
5. Guarda la configuración y vuelve al importador en modo dinámico.

Si dos botones tienen el mismo texto, la configuración puede necesitar un selector CSS más preciso, que es una opción avanzada. No admite JavaScript escrito por el usuario, accesos privados ni secuencias de pago o permisos. No automatiza botones dentro de otros iframes o componentes cerrados.

### Revisar duplicados y posibles equivalentes antes de importar

Disponible, ya importado y posible equivalente no significan lo mismo.

1. Filtra Disponibles para ver resultados sin coincidencia detectada.
2. Revisa Ya importados para reconocer los bloqueados. Puedes seleccionarlos para descartar resultados, pero no para duplicarlos en la biblioteca.
3. En Posibles equivalentes compara el nombre, la URL y la función con el widget existente. Seleccionarlo masivamente para descartar no autoriza una importación automática.
4. Usa el ojo para comprobar un caso dudoso y el botón + si decides incorporarlo individualmente.

La normalización de una URL puede ignorar diferencias de idioma o presentación en proveedores conocidos. No demuestra equivalencia funcional entre dos webs distintas. Dos calculadoras con nombres parecidos pueden tener fórmulas, países o impuestos diferentes; no borres una únicamente por su parecido de nombre.

### Continuar una búsqueda guardada sin empezar desde cero

El importador conserva un único borrador, separado de la biblioteca.

1. Sal del importador cuando necesites revisar otra cosa. El escaneo se pausa y guarda cola, resultados y campos editados cuando el almacenamiento lo permite.
2. Vuelve a Importar repositorio y comprueba el repositorio y el modo de lectura recuperados.
3. Pulsa Continuar búsqueda si hay páginas pendientes.
4. Si quieres otra URL o cambias la configuración de lectura, revisa la confirmación antes de reemplazar el borrador anterior.

Un aviso de almacenamiento lleno significa que no debes dar por guardado el trabajo. No cierres confiando en una reanudación que el navegador haya rechazado. Borrar los datos del navegador elimina el borrador; no sustituye una copia completa ni conserva un historial ilimitado de búsquedas.

## 10. Auditoría de favoritos

1. Abre **Auditoría de favoritos** desde la primera barra o **Ajustes → Datos**. Si ya existe una comprobación, se muestra sin volver a consultar todas las webs.
2. Pulsa **Actualizar auditoría** cuando quieras una comprobación nueva. Espera a que termine y revisa la fecha: un resultado antiguo no garantiza el estado actual de una página.
3. Usa la búsqueda, el selector de resultados o los contadores para reducir la lista. Distingue no disponible confirmado de tiempo agotado, bloqueo o error de red.
4. Para comprobar un caso, abre su enlace con clic derecho en otra pestaña. El ojo permite una vista previa, pero algunas páginas no aceptan incrustación y deben revisarse en una pestaña normal.
5. Si la dirección cambió, pulsa editar, corrige **título y URL** y guarda. Vuelve a comprobar el estado con su botón individual; cambiar solo el título no repara una dirección errónea.
6. Selecciona manualmente los enlaces que quieras tratar. **Seleccionar candidatos** propone los casos confirmados por la auditoría, no todos los errores temporales.
7. Antes de **Eliminar seleccionados**, revisa la selección y el alcance de la sincronización nativa. El aspa de una fila actúa sobre ese favorito individual. No elimines cientos de enlaces solo porque una consulta haya fallado.
8. Exporta el informe si necesitas conservar los resultados de esa comprobación. El informe no sustituye la copia completa de tus datos.

Busca, filtra por estado o pulsa los contadores. Puedes seleccionar manualmente resultados, abrir el enlace en otra pestaña, editar título y URL, actualizar su estado individual o eliminarlo con confirmación. La selección automática de candidatos se limita a inexistencia confirmada; red, espera, restricciones y errores temporales no demuestran que un enlace haya desaparecido.

Con escritura bidireccional activa, los cambios y eliminaciones se reflejan en el navegador. Lee la confirmación antes de borrar. La auditoría consulta directamente tus URLs y no garantiza aislamiento de redes privadas.

### Interpretar disponible, no disponible y no concluyente

La auditoría registra lo que pudo comprobar en un momento concreto, no una verdad permanente sobre la web.

1. Revisa la fecha de la comprobación. Usa Actualizar auditoría si necesitas un estado reciente.
2. Distingue un resultado confirmado de página inexistente de un tiempo de espera agotado, una restricción o un error de red.
3. Abre manualmente un caso no concluyente en una pestaña normal antes de decidir qué hacer.
4. Si varios sitios fallan a la vez, comprueba tu conexión, VPN o restricciones del navegador antes de eliminar favoritos.

Un bloqueo, una redirección o una página que exige autenticación pueden impedir una comprobación automática aunque el enlace siga siendo útil. Seleccionar candidatos limita la propuesta automática; no convierte todos los errores temporales en enlaces inútiles. Conserva una copia antes de cualquier eliminación masiva.

### Reparar un enlace desde la auditoría

Dónde: fila del enlace → botón de edición.

1. Abre el enlace con clic derecho para comprobar si la página se ha movido.
2. Si encuentras la dirección oficial nueva, vuelve a la auditoría y edita título y URL del mismo favorito.
3. Guarda y pulsa el botón individual de actualizar estado para volver a consultar esa URL.
4. Comprueba el favorito en su carpeta original, no solo la fila del informe.

Cambiar el nombre no corrige un destino roto. La vista previa puede fallar por bloqueo de iframe aunque la página abra bien en una pestaña. Si la sincronización bidireccional está activa, revisa también el gestor de marcadores del navegador. El aspa elimina el favorito de esa fila; no es simplemente cerrar un resultado de búsqueda.

## 11. Aspecto, fuentes e idiomas

1. Pulsa el engranaje **Ajustes** y abre **Aspecto**. Elige un tema en la lista de la izquierda y el modo Claro u Oscuro.
2. A la derecha, **Subir imagen** permite elegir un fondo local. Comprueba la previsualización completa y ajusta su opacidad antes de guardar. **Quitar fondo** elimina esa imagen del ajuste, no el archivo original de tu equipo.
3. En **Fuente de la interfaz**, elige Default para seguir la tipografía del tema o selecciona otra familia. Solo se usan fuentes instaladas y sus alternativas; no se descargan fuentes externas.
4. La tipografía y el tamaño del saludo tienen controles independientes en Principal. Cambiar la fuente general no equivale a modificar ese saludo.
5. En **Principal**, selecciona Español o English y guarda. Recorre una pantalla y vuelve a Ajustes para comprobar el cambio. La extensión no traduce automáticamente contenido privado que acabes de escribir.
6. Al cambiar de modo, los favicons monocromos detectados se adaptan al fondo. Los de colores se conservan; la calidad y resolución del icono original siguen siendo una limitación del sitio.

En **Principal**, elige español o inglés, los dos idiomas disponibles. Una configuración antigua con otro idioma pasa a español. Las traducciones guardadas se muestran sin reescribir los originales. Si editas un título, descripción o tipo, una traducción anterior no debe sustituir ese texto. Los campos aún sin traducción revisada y el contenido de iframes externos pueden permanecer en su idioma original.

### Ajustar el aspecto sin cambiar tus datos

Dónde: Ajustes → Aspecto.

1. Elige un tema de la lista y luego Claro u Oscuro. Son controles relacionados, pero no son el mismo ajuste.
2. Para el fondo utiliza Subir imagen y revisa la previsualización. Ajusta la opacidad para que los textos sigan siendo legibles.
3. Selecciona la fuente de interfaz. Default sigue la elección del tema; las demás dependen de las fuentes instaladas.
4. Guarda y comprueba una tabla, una tarjeta y el panel lateral para valorar la legibilidad.

Quitar fondo elimina la imagen del ajuste de DashboardDP, no el archivo de tu ordenador. La tipografía del saludo tiene su configuración independiente. Los favicons monocromos detectados ajustan su tono al fondo; los logotipos de color se conservan. Una imagen original pequeña o con fondo opaco puede seguir teniendo limitaciones visuales.

### Qué cambia al elegir español o inglés

El idioma de la interfaz no es un servicio de traducción automática de tus datos personales.

1. Abre Ajustes → Principal y elige Español o English.
2. Guarda y comprueba botones, formularios y mensajes. Las traducciones revisadas del catálogo pueden mostrarse en el idioma elegido.
3. Si editas el texto original de un widget, no des por válida su traducción anterior: debe corresponder a la nueva redacción.
4. Para contenido propio, conserva tú sus versiones traducidas cuando proceda. Cambiar el selector no envía tus notas, favoritos o textos a un traductor externo.

Los contenidos de una herramienta incrustada pertenecen a su proveedor y pueden seguir en otro idioma. Una configuración antigua con un idioma retirado usa español. Si un texto del producto queda sin traducir, comunica la pantalla y la frase exacta; no hace falta adjuntar tu copia privada.

## 12. Copias, papelera y restauración

1. Antes de actualizar, importar una copia o hacer una limpieza grande, abre **Ajustes → Datos** y la opción de **Copia completa**.
2. Pulsa **Descargar copia completa (.json)**. En el diálogo de guardado elige una carpeta privada fuera de la extensión. Espera a que termine la descarga y comprueba que el archivo existe y no está vacío.
3. Conserva al menos una versión anterior. El JSON incluye datos personales sin cifrar; no lo subas al repositorio ni lo adjuntes a una incidencia pública.
4. Para recuperar un elemento recién borrado, abre **Papelera**, localízalo y utiliza restaurar. Esto no es la restauración de todo el JSON.
5. Para recuperar una copia completa, exporta antes el estado actual y utiliza **Restaurar copia completa (.json)**. Selecciona el archivo correcto y lee la confirmación: reemplaza el estado del destino, no suma únicamente lo que falte.
6. Después revisa favoritos, grupos, espacios, biblioteca, notas, tareas y proyectos. Si has cambiado de equipo, perfil o navegador, sigue el manual de instalación para reconfigurar sincronización y conexiones.
7. No borres los datos de DashboardDP para intentar evitar duplicados antes de restaurar. Mantén la copia y la instalación actual hasta comprobar la recuperación en un perfil separado si necesitas ensayarla.

La papelera es temporal: hasta 250 entradas y 30 días; al alcanzar el límite puede eliminar entradas antes. Restaurar desde la papelera y restaurar una copia completa son operaciones distintas. La copia completa reemplaza el estado del destino. Exporta el estado actual antes y revisa la confirmación.

Los tokens de cuentas no se exportan. Tras reinstalar o cambiar de perfil, revisa datos, autoriza calendarios y configura de nuevo la carpeta nativa antes de activar escritura. Sigue el [manual de recuperación](MANUAL_INSTALACION.md).

### Preparar una copia antes de actualizar

Dónde: Ajustes → Datos → Copia completa.

1. Pulsa Descargar copia completa (.json) y espera a que finalice la descarga.
2. Guarda el archivo en una ubicación privada fuera de la carpeta de la extensión. Conserva también una versión anterior.
3. Comprueba nombre, fecha y tamaño. Un archivo vacío o una descarga incompleta no es una copia utilizable.
4. Solo después sustituye archivos de la extensión siguiendo el manual de instalación, manteniendo la misma carpeta y sin desinstalarla.

Exportar HTML no es lo mismo: sirve para marcadores y no conserva toda la biblioteca, notas, proyectos y ajustes. El JSON completo contiene datos personales sin cifrar y no debe publicarse en GitHub. La copia no incluye sesiones o tokens de calendario; esas cuentas requieren nueva autorización cuando corresponda.

### Recuperar un elemento borrado y restaurar una copia completa

Son dos procedimientos distintos. Elige primero el de menor alcance que resuelva el problema.

1. Si has borrado un elemento recientemente, abre Papelera, localízalo y pulsa restaurar.
2. Comprueba su regreso en la colección adecuada. La papelera tiene límites de tiempo y cantidad; no es un archivo permanente.
3. Si necesitas volver al estado completo de una copia, exporta antes el estado actual.
4. Utiliza Restaurar copia completa, elige el JSON correcto y confirma solo después de leer qué se reemplaza.
5. Revisa favoritos, notas, tareas, proyectos, widgets y conexiones pendientes en el resultado.

No borres primero los datos del navegador para evitar supuestos duplicados. Restaurar una copia completa reemplaza el estado, no añade únicamente lo que falte. Ensaya en un perfil separado si quieres comprobar una copia sin arriesgar tu instalación habitual.

### Cambiar de equipo o navegador sin perder la biblioteca

El almacenamiento de DashboardDP pertenece al perfil del navegador, no a la carpeta que contiene los archivos de la extensión.

1. En el origen, exporta una copia completa reciente y conserva una segunda copia privada.
2. Instala la extensión en el destino y restaura el JSON desde Ajustes → Datos.
3. Comprueba varios widgets, notas, grupos y proyectos antes de retirar el equipo anterior.
4. Revisa la carpeta de marcadores nativos del nuevo perfil antes de habilitar escritura bidireccional.
5. Vuelve a autorizar Google o Microsoft si utilizas calendarios conectados.

Copiar solamente la carpeta de la extensión no equivale a copiar tus datos. El catálogo público sirve como base de herramientas compartidas, pero no sustituye el respaldo de tus widgets personales, favoritos de widgets, ajustes o distribuciones de barras.

## 13. Permisos y servicios externos

1. Cuando una función solicite permiso, comprueba qué sitio o capacidad necesita. Puedes cancelarlo y seguir usando las funciones locales que no lo requieran.
2. Las conexiones de calendario, la consulta de festividades y la lectura de repositorios son opcionales. No introduzcas contraseñas o claves secretas en campos destinados a una URL de widget.
3. Cierra las vistas previas y los bloques externos que no estés usando. Cerrar un iframe libera esa instancia, pero no revoca los permisos que hayas concedido al navegador.
4. Para retirar permisos, entra en los detalles de DashboardDP en la página de extensiones del navegador. Desconectar una cuenta y revocar permisos del sitio no son necesariamente la misma operación.
5. Si una web funciona en su pestaña pero rechaza el iframe, revisa sus condiciones y su botón oficial de incrustación. DashboardDP no elude bloqueos del proveedor ni garantiza que el servicio siga siendo gratuito.
6. Para comunicar un fallo, indica navegador, versión de DashboardDP, pantalla, pasos y resultado esperado. Usa ejemplos inventados y oculta URLs privadas, notas, tokens y datos de tus cuentas antes de enviar una captura.

Consulta [Privacidad](../PRIVACIDAD.md), [Seguridad](../SECURITY.md) y [Licencias](../THIRD-PARTY-NOTICES.md). Para pedir ayuda, describe el problema sin adjuntar copias personales, tokens ni capturas privadas.

### Resolver un widget que no carga sin quitar protecciones

Primero identifica si falla la URL, el código de incrustación o una restricción del proveedor.

1. Abre la dirección oficial en una pestaña normal y comprueba que siga existiendo.
2. Busca su opción oficial de incrustar y compara el src con el guardado en tu ficha.
3. Prueba la vista previa con datos ficticios. Si solo falla dentro del iframe, el proveedor puede no permitir esa integración.
4. Revisa los permisos concedidos desde los detalles de la extensión. No habilites cuentas, pagos o permisos innecesarios para intentar forzar una herramienta pública.

Una URL HTTPS no garantiza calidad, seguridad ni disponibilidad permanente. Cerrar el bloque libera esa instancia, pero no borra los datos que el servicio haya almacenado por su cuenta. No añadas scripts o instrucciones encontradas en una web para eludir los bloqueos del navegador.

### Comunicar un problema con información útil y sin datos privados

Antes de pedir ayuda prepara una reproducción pequeña.

1. Copia la versión que aparece en Ajustes → Acerca de y anota el navegador utilizado.
2. Escribe la pantalla y los pasos exactos, por ejemplo Biblioteca → filtro Texto → Cambiar tipo.
3. Describe por separado lo que esperabas y lo que realmente ocurre. Indica si sucede siempre o solo con un widget concreto.
4. Si adjuntas una captura, oculta nombres, URLs privadas, notas y datos de cuentas. Para un iframe utiliza un ejemplo público si puedes.
5. No publiques copias completas, tokens, contraseñas o credenciales en una incidencia.

Una captura de una ventana vacía no permite saber si el problema es un filtro, una carga pendiente o un fallo. Añadir el paso anterior y el nombre del control suele ser más útil que enviar toda tu biblioteca personal.
